# RecipeCuratorApplication - Spoonacular API, Java, Android Studio, Firebase
Hey everyone! Welcome to the Recipe Curator!

The Recipe Curator is an android mobile application that allows a user to enter in certain ingredients and calorie/macro restrictions in order to find a recipe that is suitable for their needs!
This project allows users to create and verify an account with their email through Firebase to then save favorite recipes under their account information. Enjoy!
